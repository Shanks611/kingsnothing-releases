# KingsNothing

Installer and automatic updates for **KingsNothing**.

- **New here:** open [Releases](https://github.com/Shanks611/kingsnothing-releases/releases/latest) and download `KingsNothing_..._x64-setup.exe`.
- **Already installed:** the app shows **Update** in its title bar when a new version is out. One click installs it.

Every update is signed; the app refuses any file that wasn't.
